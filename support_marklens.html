Supported Files

MarkLens supports local Markdown and HTML files:

  • Markdown: `.md`, `.markdown`
  • HTML: `.html`, `.htm`

Import Files

Open MarkLens, tap the add button, and choose files from the iOS Files picker. Imported files are copied into local app storage.

Preview and Source

Open a document and switch between rendered preview and source text to inspect formatting or markup.

Privacy

MarkLens does not collect personal data or upload imported documents.

Read the privacy policy

Troubleshooting

If a file does not render as expected, check that it is UTF-8 encoded and that linked local images use paths available from the imported document location.
